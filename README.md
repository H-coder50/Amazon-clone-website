# 🛒 Amazon Clone Website

A front-end clone of the Amazon website created using **HTML and CSS** as a learning and practice project. This project helped me understand website structure, styling, layouts, navigation bars, and how to recreate a real-world website design.

## 🚀 Project Overview

This project is inspired by Amazon's e-commerce website. I recreated its homepage layout, including the navigation bar, search section, delivery location, account section, cart, and product/hero sections.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Amazon-style navigation bar
- Amazon logo section
- Delivery location section
- Search bar with category dropdown
- Sign-in and account section
- Returns & Orders section
- Shopping cart section
- Hero section with background image
- Product image sections
- Hover effects and borders
- Flexbox layout

## 📚 What I Learned

While building this project, I practiced and learned:

- HTML page structure
- Divs and semantic elements
- Classes and IDs
- Linking CSS files with HTML
- CSS selectors
- Box model (`margin`, `padding`, `border`)
- `box-sizing: border-box`
- Flexbox
- `align-items`
- `justify-content`
- Background images
- Image sizing using `background-size`
- Navbar styling
- Hover effects
- Font Awesome icons
- Website layout and spacing

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or run it using the Live Server extension.
